# Отобранные фрагменты реализации

Два небольших фрагмента из версии `9b13cd791b9253fc80dd5689c8b628dbbba32e6e` показывают инженерный приём и его проверку. Это исторический код, ранее опубликованный под MIT; [условия MIT](../licenses/MIT-legacy.txt) сохранены. Фрагменты нельзя считать полной реализацией или самостоятельным тестовым комплектом.

- [Атомарное решение](atomic-decision.md): как второе конкурентное решение получает конфликт.
- [Проверка конкуренции](concurrency-check.md): почему проверяют и число успешных решений, и связанный статус.

Схема БД, прикладные правила, интеграционные workflows и окружение приложения не включены. Код создан с использованием LLM; роль Mikhail V. — постановка задач и управление разработкой с контролем результата.
