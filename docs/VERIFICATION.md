# Проверки и честные ограничения

## Полная реализация

Контрольная версия: `9b13cd791b9253fc80dd5689c8b628dbbba32e6e`, 1 ноября 2026 года.

- Ранее выполнены 29 backend, 24 unit и 11 PostgreSQL integration tests — всего 64. Отчёт обновления и успешные GitHub CI/Secret scan для этой версии проверены при подготовке портфолио. Это не заявление о повторном запуске всех 64 тестов в репозитории портфолио.
- Интеграционные проверки включают конкурентные согласования, откат при ошибке аудита, актуальные права, отзыв JWT, дедупликацию и защиту согласованного документа.
- При подготовке портфолио повторно проверены HTTPS health, вход администратора, запрет анонимного доступа, чтение защищённых API, общий JWT для backend и загрузка UI без browser errors.
- Проверены все 36 коммитов исходной истории сканером секретов; совпадений с семью рабочими секретными значениями в 326 исторических blob не обнаружено. Это проверка конкретного снимка, а не гарантия отсутствия всех возможных уязвимостей.

## Публичное портфолио

Здесь CI проверяет локальные ссылки, изображения и допустимый состав файлов. Полное приложение и его тестовая инфраструктура остаются в приватном репозитории. Фрагменты служат для чтения на собеседовании, не являются самостоятельным приложением.

## Ограничения

Нет подтверждённых коммерческих внедрений, измеренной экономии или оценки точности LIVE-моделей. LOCAL использует правила и парсеры. Очередь воркеров, outbox, OCR и CRM/ERP-интеграции требуют разработки. Две API-реализации создают риск рассогласования правил. n8n-шаблоны не означают активированные production-сценарии.

В ранее снятом экране списка документов обнаружено отображение `NaN` вместо размера файла на синтетических данных; этот UI-дефект требует отдельного исправления. На странице демонстрации используются обзор и согласования. Проверка портфолио не является аудитом безопасности всей платформы.
